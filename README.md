# Tecnologia

Este projeto é um Progressive Web App (PWA), desenvolvido com o objetivo de oferecer uma experiência prática e acessível diretamente pelo navegador.

Os PWAs podem combinar a facilidade de acesso de um site com recursos normalmente associados a aplicativos instalados, dependendo da implementação e do suporte do navegador e do dispositivo.

# O que é um PWA?

Um Progressive Web App é uma aplicação web que pode ser instalada em dispositivos compatíveis, permitindo que o usuário a acesse pela tela inicial sem precisar procurá-la no navegador toda vez.

Entre as possibilidades dessa tecnologia estão:

- Instalação: acesso pelo ícone do aplicativo na tela inicial, quando compatível.
- Acesso pelo navegador: utilização sem necessariamente instalar o aplicativo.
- Interface adaptável: possibilidade de adaptar a experiência a diferentes tamanhos de tela.
- Experiência semelhante à de um aplicativo: abertura em uma janela própria, dependendo da configuração.
- Funcionamento offline: possibilidade de disponibilizar recursos sem conexão, quando implementado com as estratégias adequadas de cache e armazenamento.

A disponibilidade desses recursos depende da implementação do projeto e das capacidades do navegador utilizado.

# Como acessar

O aplicativo pode ser disponibilizado por meio de uma hospedagem web compatível com HTTPS.

Para utilizá-lo:

1. Acesse o endereço publicado do aplicativo em um navegador compatível.
2. Utilize as funcionalidades disponíveis normalmente.
3. Caso a instalação seja oferecida pelo navegador, siga as instruções exibidas para adicionar o aplicativo à tela inicial.

A instalação não exige necessariamente uma publicação em uma loja de aplicativos tradicional.

# Publicação

Um PWA pode ser publicado em um serviço de hospedagem web compatível com HTTPS. Após a publicação, os usuários podem acessar o endereço do aplicativo e instalá-lo quando o navegador oferecer suporte.

O processo exato de publicação depende da estrutura e das ferramentas utilizadas neste projeto.
